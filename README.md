# AI Evaluation Portfolio

A practical portfolio of AI evaluation, data annotation, LLM quality assessment, search quality evaluation, RAG evaluation, and human-AI agreement projects.

## Projects

### Project 1 — Sentiment Classification Evaluation
Human annotation and AI prediction comparison using Label Studio, Python, AgentRouter, and Hugging Face.

### Project 2 — LLM Response Quality Evaluation
Evaluation of AI-generated responses for correctness, relevance, completeness, clarity, instruction following, and hallucination.

### Project 3 — Search Quality Evaluation
Evaluation of search results for relevance and usefulness.

### Project 4 — RAG Evaluation
Evaluation of retrieval quality, answer correctness, relevance, and groundedness.

### Project 5 — Human vs AI Agreement
Analysis of agreement and disagreement between human annotations and AI predictions.
